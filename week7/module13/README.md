# Week 7 - Module 13

# Containerization using Docker

## Overview

This module introduces Docker, one of the most widely used containerization platforms. It covers Docker commands, Docker images, Docker Compose, Docker Engine, Docker storage, Docker networking, and container orchestration.

## Topics Covered

- Introduction to Docker
- Docker Commands
- Docker Run
- Docker Images
- Docker Compose
- Docker Engine
- Docker Storage
- Docker Networking
- Container Orchestration (Kubernetes)

## Learning Outcome

Understand Docker fundamentals, manage containers using Docker commands, work with Docker images and networking, and gain an introduction to Kubernetes for container orchestration.
