# Module 12 - DevOps and CI/CD Notes

## 1. What is DevOps?

DevOps is a software development methodology that combines Development (Dev) and Operations (Ops). It promotes collaboration, automation, and continuous improvement to deliver software faster and more reliably.

---

## 2. Goals of DevOps

- Faster software delivery
- Better collaboration between teams
- Improved software quality
- Faster bug fixing
- Automated workflows
- Continuous feedback

---

## 3. Benefits of DevOps

- Shorter development cycle
- Higher deployment frequency
- Reduced failures
- Better customer satisfaction
- Improved system stability

---

## 4. Key DevOps Practices

### Continuous Integration (CI)

Developers frequently merge code into a shared repository. Every code change is automatically built and tested.

Advantages:
- Detects bugs early
- Improves code quality
- Saves time

---

### Continuous Delivery (CD)

Automatically prepares software for release after passing all tests.

Advantages:
- Faster releases
- Less manual work
- Reliable deployments

---

### Continuous Deployment

Every successful code change is automatically deployed to production without manual approval.

---

## 5. Difference Between CI and CD

| Continuous Integration | Continuous Delivery |
|------------------------|--------------------|
| Integrates code frequently | Releases software after testing |
| Focuses on build and testing | Focuses on deployment |
| Finds bugs early | Makes releases faster |

---

## 6. Popular CI/CD Tools

### Jenkins
- Open-source automation server
- Supports many plugins
- Used to build CI/CD pipelines

### GitHub Actions
- Built into GitHub
- Uses YAML workflow files
- Automates build, test, and deployment

### GitLab CI/CD
- Integrated with GitLab
- Easy pipeline management

### CircleCI
- Cloud-based CI/CD platform
- Fast and scalable

---

## 7. Summary

DevOps combines development and operations to improve software delivery through automation and collaboration. CI/CD helps teams build, test, and deploy applications quickly and efficiently.
