# Week 7 - Module 15

# Introduction to Cloud Computing and AWS

## Overview

This module introduces the fundamentals of Cloud Computing and Amazon Web Services (AWS). It covers cloud concepts, service and deployment models, virtualization, and major AWS services such as EC2, ECS, S3, EBS, VPC, ELB, RDS, DynamoDB, Lambda, and API Gateway.

## Topics Covered

- Cloud Computing Fundamentals
- Virtualization
- Service-Oriented Architecture (SOA)
- Cloud Service Models (IaaS, PaaS, SaaS)
- Cloud Deployment Models
- AWS Cloud Providers
- Amazon EC2
- Amazon ECS
- Amazon S3
- Amazon EBS
- Amazon VPC
- Elastic Load Balancer (ALB & NLB)
- Amazon RDS
- Amazon DynamoDB
- AWS Lambda
- AWS API Gateway

## Learning Outcome

Understand cloud computing concepts, AWS architecture, and core AWS services used to build scalable, secure, and highly available cloud applications.
