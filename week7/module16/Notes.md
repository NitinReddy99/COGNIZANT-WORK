# Module 16 - Generative AI Fundamentals

## 1. What is Generative AI?

Generative AI is a type of Artificial Intelligence that creates new content such as text, code, images, music, and videos based on user input.

Examples:
- ChatGPT
- GitHub Copilot
- DALL·E
- Gemini

---

## 2. Generative AI vs Traditional AI

| Generative AI | Traditional AI |
|---------------|----------------|
| Creates new content | Classifies or predicts data |
| Generates text, code, images | Detects patterns and makes decisions |
| Learns from large datasets | Uses predefined models |

---

## 3. Applications of Generative AI

- Code generation
- Chatbots
- Content writing
- Image generation
- Language translation
- Documentation
- Test case generation

---

## 4. Evolution of Generative AI

- 1960s – Early Chatbots
- 2014 – Generative Adversarial Networks (GANs)
- 2020 – GPT-3
- 2022 – ChatGPT
- GitHub Copilot and modern AI coding assistants

# Prompt Engineering

## What is Prompt Engineering?

Prompt Engineering is the process of writing clear and effective instructions for AI models to generate accurate results.

---

## Prompting Techniques

### Zero-shot Prompting

Ask the AI to perform a task without providing examples.

Example:

Write a Java program to reverse a string.

---

### Few-shot Prompting

Provide one or more examples before asking the AI to perform the task.

Example:

Input: Hello
Output: olleH

Input: Java
Output: avaJ

Now reverse "Python".

---

### Chain-of-Thought Prompting

Ask the AI to explain its reasoning step by step before providing the final answer.

---

## Best Practices

- Write clear instructions.
- Provide sufficient context.
- Specify the desired output format.
- Refine prompts based on results.
- Keep prompts simple and specific.

---

## Ethical Considerations

- Avoid biased prompts.
- Protect sensitive information.
- Verify AI-generated responses.
- Use AI responsibly.
- Respect copyright and licensing.

# GitHub Copilot

## What is GitHub Copilot?

GitHub Copilot is an AI-powered coding assistant that helps developers write code faster by providing intelligent code suggestions.

---

## Features

- Code completion
- Function generation
- Documentation generation
- Test case generation
- Code refactoring
- Boilerplate code creation

---

## Supported IDEs

- Visual Studio Code
- Visual Studio
- JetBrains IDEs
- Neovim

---

# Setup and Configuration

1. Install Visual Studio Code.
2. Install the GitHub Copilot extension.
3. Sign in with a GitHub account.
4. Enable GitHub Copilot.
5. Start coding and accept suggestions using the Tab key.

---

# Core Capabilities

- Auto-complete code
- Generate functions
- Generate comments
- Generate documentation
- Create unit tests
- Improve existing code

---

# Security Risks

AI-generated code may contain:

- Security vulnerabilities
- Incorrect logic
- Hallucinated APIs
- Outdated code

Always review generated code before using it.

---

# Privacy and Licensing

- Do not enter confidential information into AI tools.
- Follow your organization's privacy policies.
- Check licensing requirements before using generated code.
- Give attribution when required.

---

# Responsible AI Usage

- Verify generated code.
- Test thoroughly.
- Review for security issues.
- Use AI as a coding assistant, not a replacement for human judgment.

---

# Summary

Generative AI helps developers create code, documentation, and other content efficiently. GitHub Copilot improves productivity by providing AI-powered coding assistance. Developers should use prompt engineering techniques, review AI-generated code carefully, and follow ethical and secure AI practices.
